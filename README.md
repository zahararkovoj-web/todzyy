# Проект по информатике: тест на цифровую нагрузку

Сайт-чат с подсчётом баллов для оценки цифровой нагрузки.  

## Функционал
- Интерактивный чат с подсчётом баллов по ответам.  
- Адаптивная верстка под мобильные устройства.  

## Технологии
- HTML5, CSS3, JavaScript.  
- Хостинг: GitHub Pages.
